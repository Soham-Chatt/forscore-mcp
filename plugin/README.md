# forScore plugin for Claude Code

Gives Claude the `forscore` MCP server and the `forscore-metadata` skill, so it can read and
clean up the metadata in a forScore sheet-music library: titles, composers, catalogue
references, keys, genres and tags. Changes are previewed, then imported through forScore's own
Metadata CSV import, where forScore shows its own preview before saving.

Requires a Mac with forScore, [uv](https://docs.astral.sh/uv/), and Full Disk Access for the
app running Claude Code. See the [main README](../README.md) for setup, safety and usage.
